# Online Retail Analytics — SQL (PostgreSQL) + Python (Pandas)

Учебный проект: анализ реальных продаж интернет-магазина с помощью PostgreSQL и Python.

## Датасет

**Online Retail** — реальные транзакции британского интернет-магазина подарков за 01.12.2010–09.12.2011: 541 909 строк, 4 338 клиентов, 37 стран.

- Источник: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/352/online+retail) (Chen, Sain, Guo, 2012)
- Файл взят из открытого репозитория Databricks (`Spark-The-Definitive-Guide`), лицензия CC BY 4.0.

После очистки (убраны отменённые заказы и строки без ID клиента) осталось **397 884 строки**.

## Стек

- **PostgreSQL** — хранение данных
- **Python** — `pandas` для очистки данных и графиков, `psycopg2` для подключения к Postgres

## Как это работает

1. `load_data.py` читает сырой CSV, чистит его в pandas и построчно загружает в таблицу `orders` в Postgres.
2. В `sql/` лежат 4 обычных SQL-запроса — считают выручку по месяцам, топ товаров и т.д.
3. `analysis.py` выполняет эти запросы (через `psycopg2`), сохраняет результат в CSV и строит графики.

## Ключевые находки

- Всего выручки за период — **≈8.9 млн £**, 18 532 заказа, 4 338 клиентов.
- **86% выручки — Великобритания** (7.3 млн £ из 8.9 млн), но у Нидерландов и Ирландии выручка заметная при считаных клиентах (9 и 3 соответственно) — то есть там средний чек кратно выше, похоже на нескольких оптовых покупателей, а не масс-рынок.
- **Декабрь 2011 в данных неполный** — обрывается 9 числа. Это особенность датасета, а не спад продаж — важно не спутать при интерпретации графика.

```
│   ├── 01_overview.sql
│   ├── 02_monthly_revenue.sql
│   ├── 03_top_products.sql
│   └── 04_revenue_by_country.sql
├── charts/            # PNG-графики
└── data/               # результаты запросов (CSV)
```
